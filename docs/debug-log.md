# L06 Алдаа шалгасан тэмдэглэл

## 1. Шалгах асуудал
GitHub дээр файл зөв хавтас дотор байгаа эсэхийг шалгах.

## 2. Боломжит шалтгаанууд
1. Файлын нэр буруу байх.
2. Файл өөр хавтас дотор байх.
3. Өөрчлөлт commit хийгдээгүй байх.

## 3. Миний хийсэн шалгалт
- Repository-ийн `docs` хавтсыг нээсэн.
- Файлын нэр болон байрлалыг шалгасан.
- Commit хийгдсэн эсэхийг шалгасан.

## 4. Үр дүн
Энэ шалгалтаар файлын нэр, байрлал болон commit-ийн төлөвийг нягтална.

## 5. Миний дүгнэлт
Алдаа гарсан үед шууд олон зүйл өөрчлөхгүй. Нэг боломжит шалтгааныг шалгаж, үр дүнг тэмдэглэх хэрэгтэй.

## Шалгалтын бодит үр дүн
- **Шалгасан зүйл:** Файлын нэр болон байрлал.
- **Хүлээсэн үр дүн:** Файл `docs` хавтас дотор байх.
- **Ажигласан үр дүн:** `ai-log.md` болон `debug-log.md` хоёр файл `docs` хавтас дотор харагдсан.
- **Дүгнэлт:** Файлын байрлал зөв байна. Энэ шалгалтаар зөвхөн нэр, байрлалыг баталгаажуулсан.

- ## 6. Merge conflict судалгаа

- **Эх сурвалж:** GitHub Docs — Merge conflicts
- **Юу сурсан:** Хоёр branch нэг хэсгийг өөр өөрөөр өөрчилсөн үед merge conflict үүсэж болно.
- **Шийдэх арга:** Хоёр хувилбарыг харьцуулж, аль өөрчлөлтийг үлдээхээ шийдээд conflict тэмдэглэгээнүүдийг арилгана.
- **Миний дүгнэлт:** Merge хийхээс өмнө өөрчлөлтүүдийг шалгаж, зөрчил гарвал шууд сонголт хийхгүйгээр агуулгыг нь ойлгох хэрэгтэй.
