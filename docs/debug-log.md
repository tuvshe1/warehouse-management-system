# L06 Алдаа шалгасан тэмдэглэл

## 1. Шалгах асуудал

GitHub дээр үүсгэсэн файлууд зөв хавтас дотор хадгалагдсан эсэхийг шалгах.

## 2. Боломжит шалтгаанууд

1. Файлын нэр буруу байх.
2. Файл өөр хавтас дотор байх.
3. Өөрчлөлт commit хийгдээгүй байх.

## 3. Хүлээсэн үр дүн

`ai-log.md` болон `debug-log.md` файлууд `docs` хавтас дотор харагдах.

## 4. Миний хийсэн шалгалт

- Repository-оо нээсэн.
- `docs` хавтас руу орсон.
- Хоёр файлын нэр болон байрлалыг шалгасан.

## 5. Ажигласан үр дүн

`ai-log.md` болон `debug-log.md` хоёр файл `docs` хавтас дотор харагдсан.

## 6. Merge conflict судалгаа

- **Эх сурвалж:** [GitHub Docs — Merge conflicts](https://docs.github.com/en/pull-requests/reference/merge-conflicts)
- **Юу сурсан:** Хоёр branch-ийн өөрчлөлт хоорондоо зөрчилдвөл merge conflict үүсэж болно.
- **Шийдэх арга:** Зөрчилтэй хэсгүүдийг харьцуулж, зөв өөрчлөлтүүдийг сонгон зөрчлийн тэмдэглэгээг арилгана.
- **Миний дүгнэлт:** Зөрчил гарсан үед өөрчлөлт бүрийг ойлгож байж шийдэх хэрэгтэй.

## 7. Миний дүгнэлт

Алдаа шалгахдаа нэг боломжит шалтгааныг сонгож, үр дүнг ажиглах нь чухал. Энэ удаа би файлын нэр, байрлалыг шалгасан. Merge conflict-ийн тухай албан ёсны зааврыг судалж, ийм зөрчлийг хэрхэн шийдэх талаар ойлгосон. Би merge conflict-ийг өөрөө үүсгэж туршаагүй.
