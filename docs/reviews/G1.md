## G1 хамгаалалтын бэлтгэл
Суралцагч өөрийн үгээр тайлбарлах ёстой:
1. Орлого, зарлага, үлдэгдлийн ялгаа.
2. JavaScript/Python filter хэрхэн ажиллаж байгаа.
3. SQL INNER JOIN хоёр хүснэгтийг SKU-аар хэрхэн холбож байгаа.
4. Duplicate SKU, 0/сөрөг тоо, insufficient stock үед яагаад үлдэгдэл өөрчлөгдөх ёсгүй.
5. Issue → branch → commit → PR → review урсгал.
6. AI-ийн аль таамаглалыг яаж шалгасан, аль нь батлагдсан/няцаагдсан.
