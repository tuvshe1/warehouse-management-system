# L08 — Өгөгдлийн сангийн загвар

## 1. Ашигласан технологи

- Өгөгдлийн сан: MySQL
- MySQL Server: 9.6.0
- Өгөгдлийн сангийн нэр: `warehouse_db`
- SQL эх файл: `docs/examples/warehouse-schema.sql`

## 2. Хүснэгтийн бүтэц

### products

Барааны үндсэн мэдээллийг хадгална.

| Багана | Тайлбар |
|---|---|
| product_id | Үндсэн түлхүүр |
| sku | Барааны давтагдашгүй код |
| product_name | Барааны нэр |
| unit | Хэмжих нэгж |
| created_at | Үүсгэсэн огноо |

`sku` талбарт UNIQUE нөхцөл тавьсан.

### warehouse_documents

Агуулахын орлого, зарлагын баримтыг хадгална.

| Багана | Тайлбар |
|---|---|
| document_id | Үндсэн түлхүүр |
| document_no | Баримтын дугаар |
| document_type | IN эсвэл OUT |
| document_date | Баримтын огноо |
| status | DRAFT эсвэл CONFIRMED |
| note | Тайлбар |

### document_items

Баримт бүрийн бараа, тоо хэмжээг хадгална.

| Багана | Тайлбар |
|---|---|
| item_id | Үндсэн түлхүүр |
| document_id | warehouse_documents хүснэгтийн гадаад түлхүүр |
| product_id | products хүснэгтийн гадаад түлхүүр |
| quantity | Барааны тоо хэмжээ |

`quantity > 0` гэсэн CHECK нөхцөлтэй. Нэг баримтад нэг барааг давхар оруулахгүй байх UNIQUE нөхцөлтэй.

## 3. Хүснэгтүүдийн холбоо

- Нэг баримт олон барааны мөртэй байж болно.
- Нэг бараа олон баримтын мөрөнд орж болно.
- `document_items` нь `products` болон `warehouse_documents` хүснэгттэй гадаад түлхүүрээр холбогдоно.

## 4. Үлдэгдэл тооцох зарчим

- Баталгаажсан IN баримт үлдэгдлийг нэмэгдүүлнэ.
- Баталгаажсан OUT баримт үлдэгдлийг бууруулна.
- DRAFT баримтыг үлдэгдэлд тооцохгүй.
- Бага үлдэгдэлтэй барааг `balance < 5` нөхцөлөөр шүүнэ.

SQL эх файлд үлдэгдэл тооцох болон бага үлдэгдэлтэй бараа шүүх SELECT query байгаа.

## 5. Бодит MySQL туршилт

Шалгасан огноо: 2026-11-16

MySQL Server: 9.6.0

### Хүснэгт үүсгэсэн шалгалт

`warehouse_db` өгөгдлийн санд дараах 3 хүснэгт үүссэн:

- products
- warehouse_documents
- document_items

### Барааны үлдэгдлийн шалгалт

Эхний орлогын баримтаар оруулсан бараануудын үлдэгдэл:

| SKU | Барааны нэр | Үлдэгдэл |
|---|---|---:|
| A01 | Цаас | 10 |
| A02 | Үзэг | 3 |
| A03 | Дэвтэр | 7 |
| A04 | Хавтас | 2 |
| A05 | Баллуур | 6 |

### Давхардсан SKU шалгалт

Туршилт: `A01` SKU-тай барааг дахин INSERT хийх.

Бодит үр дүн: `Error Code: 1062. Duplicate entry 'A01' for key 'products.sku'`

Төлөв: PASS — давхардсан SKU бүртгэгдээгүй.

### Тэг тоо хэмжээний шалгалт

Туршилт: `quantity = 0` утгатай мөр INSERT хийх.

Бодит үр дүн: `Error Code: 3819. Check constraint 'chk_quantity_positive' is violated.`

Төлөв: PASS — тэг тоо хэмжээтэй мөр бүртгэгдээгүй.

## 6. Дүгнэлт

MySQL дээр өгөгдлийн сангийн 3 хүснэгтийг үүсгэж, жишээ барааны мэдээлэл болон орлогын баримтыг оруулж шалгасан. Давхардсан SKU болон тэг тоо хэмжээний нөхцөлийг MySQL-ийн UNIQUE болон CHECK хязгаарлалтаар хориглож байгааг бодитоор баталгаажуулсан.
