# L05 — Хамрах хүрээ ба ажлын төлөвлөгөө

## Төслийн зорилго

Агуулахын барааны бүртгэл, орлого, зарлага болон үлдэгдлийг хянах сургалтын системийн шаардлага, ажлыг төлөвлөх.

## Ажлын эрэмбэ

- **Үндсэн (Must):** M1–M6 — бараа бүртгэх, орлого, зарлага, үлдэгдэл, бага үлдэгдэл, баримт шалгах.
- **Дараагийн (Should):** M7 — бараа хайх.
- **Шалгалт (Must before hand-in):** M8 — тест, баримтжуулалт, G1 нотолгоо.

## Milestone ба жижиг ажлууд

| ID | Ажил | Data / SQL | API / Logic | UI / Flow | Test / Дуусах шалгуур |
|---|---|---|---|---|---|
| M1 | Барааны бүртгэл | products хүснэгт, SKU unique | Бараа үүсгэх, давхардлыг хориглох | Барааны form | Шинэ бараа хадгалагдана; давхар SKU, дутуу талбар татгалзана |
| M2 | Орлогын бүртгэл | stock movement / орлогын мөр | Тоо хэмжээ > 0 үед нэмэх | Орлогын form | Зөв орлого үлдэгдлийг нэмнэ; 0/сөрөг үед өөрчлөлтгүй |
| M3 | Зарлагын бүртгэл | Зарлагын хөдөлгөөн | Хүрэлцээ шалгаж хасах | Зарлагын form | Хүрэлцэхгүй бол татгалзаж үлдэгдэл өөрчлөхгүй |
| M4 | Үлдэгдэл шалгах | SKU ба quantity query | SKU-аар үлдэгдэл авах | Үлдэгдлийн дэлгэц | Зөв үлдэгдэл харагдана; олдоогүй SKU мэдэгдэнэ |
| M5 | Бага үлдэгдэл | threshold query | quantity < 5 шүүх | Анхааруулгын жагсаалт | 0–4 орно; 5 ба түүнээс дээш орохгүй |
| M6 | Баримт шалгах | Баримтын талбарууд | Required field, quantity validation | Баримтын form | Дутуу/0/сөрөг утгатай баримт хадгалагдахгүй |
| M7 | Бараа хайх | SKU/name index | Хайлтын нөхцөл боловсруулах | Хайлтын хэсэг | Олдсон/олдоогүй/хоосон хайлтын үр дүн зөв |
| M8 | Тест ба шалгалт | Test data | Шалгах логик | Алдааны мессеж шалгах | 24 AC-д тестийн нотолгоо, G1 индекс бэлэн |

## Нэмэлт боломж

- Тайлангийн боломж нэмэх.
- Хэрэглэгчийн эрхийг сайжруулах.
- Интерфейсийг сайжруулах.

## Миний дүгнэлт

Ажлыг жижиг хэсгүүдэд хувааж, эхлээд үндсэн үйл ажиллагааг хийхээр эрэмбэлсэн. Нэг milestone дууссан гэж үзэхийн тулд түүний шалгуурыг тестээр шалгаж, үр дүнг тэмдэглэнэ.
