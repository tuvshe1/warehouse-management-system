## SQL JOIN

SQL JOIN нь хоёр хүснэгтийн холбоотой мэдээллийг нэгтгэж харуулахад ашиглагддаг.

Би JOIN ашиглах үед холбоотой мэдээллүүд нэг үр дүнд гарна гэж таамагласан.
