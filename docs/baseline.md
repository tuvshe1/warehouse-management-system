- **Үлдэгдэл:** тухайн агуулахад одоо байгаа барааны тоо хэмжээ.

## 4. SQL JOIN оролдлого

JOIN нь хоёр хүснэгтэд байгаа холбоотой мэдээллийг нэг үр дүнд нэгтгэн харуулна.

Жишээ хүснэгт:

**products**

| sku | product_name |
|---|---|
| A01 | Цаас |
| A02 | Үзэг |
| A03 | Дэвтэр |

**stocks**

| sku | quantity |
|---|---:|
| A01 | 10 |
| A02 | 3 |
| A03 | 7 |

SQL:
```sql
SELECT
    products.sku,
    products.product_name,
    stocks.quantity
FROM products
INNER JOIN stocks
    ON products.sku = stocks.sku
ORDER BY products.sku;
```

Хүлээгдэж буй үр дүн:

| sku | product_name | quantity |
|---|---|---:|
| A01 | Цаас | 10 |
| A02 | Үзэг | 3 |
| A03 | Дэвтэр | 7 |

Бүрэн SQL жишээ `docs/examples/product-stock-join.sql` файлд байна. MySQL дээр ажиллуулсны дараа бодит үр дүнг тэмдэглэнэ.

## 5. Мэдэхгүй болон сайжруулах зүйлс

1. INNER JOIN болон LEFT JOIN-ийн ялгааг илүү сайн ойлгох.
2. Агуулах, бараа, хөдөлгөөний хүснэгтүүдийн холбоог судлах.
3. GitHub дээр issue → branch → commit → pull request → review дарааллыг зөв ашиглах.
