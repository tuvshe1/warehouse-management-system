# L01 Суурь үнэлгээ

## Агуулахын үндсэн ойлголт

Орлого гэдэг нь бараа агуулахад орж ирэхийг хэлнэ.

Зарлага гэдэг нь бараа агуулахаас гарахыг хэлнэ.

Үлдэгдэл гэдэг нь агуулахад одоо байгаа барааны тоо юм.

## JavaScript туршилт

JavaScript дээр 5 барааны мэдээллээс үлдэгдэл 5-аас бага барааг шүүж үзсэн.

Үр дүн:

A02 Үзэг - 3 ширхэг

A04 Хавтас - 2 ширхэг

JavaScript дээр туршилтын үр дүн зөв гарсан.

## Python туршилт

JavaScript дээр хийсэн туршилтаа Python дээр давтаж үзсэн.

Үр дүн:

A02 Үзэг - 3 ширхэг

A04 Хавтас - 2 ширхэг

Python дээр туршилтын үр дүн зөв гарсан.

## SQL JOIN

SQL JOIN нь хоёр хүснэгтийн холбоотой мэдээллийг нэгтгэж харуулахад ашиглагддаг.

Би JOIN ашиглах үед холбоотой мэдээллүүд нэг үр дүнд гарна гэж таамагласан.

## Мэдэхгүй байгаа зүйлс

1. SQL JOIN-ийн төрлүүдийг сайн мэдэхгүй.
2. Агуулахын системийн бодит бүтэц ямар байхыг сайн мэдэхгүй.
3. GitHub дээр ажиллах дарааллыг илүү сайн сурах хэрэгтэй.

## Миний зорилго

1. JavaScript болон Python ашиглан өгөгдөл шүүж, агуулахын барааны мэдээлэлтэй ажиллаж сурна.
2. SQL, User Story, Acceptance Criteria болон GitHub дээр issue, branch, pull request ашиглаж сурна.

## Миний дүгнэлт

Энэ хичээлээр агуулахын орлого, зарлага болон үлдэгдлийн үндсэн ойлголтыг ойлгосон.

Мөн JavaScript болон Python дээр барааны үлдэгдэл шүүж туршиж үзсэн.

SQL JOIN болон GitHub-ийн талаар цаашид илүү сайн сурах шаардлагатай гэж ойлгосон.
