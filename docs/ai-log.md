# L06 AI ашигласан тэмдэглэл

## 1. Асуудал

GitHub дээр файл үүсгэх, хадгалах үед алдаа гарвал шалтгааныг хэрхэн олох вэ?

## 2. AI-д тавьсан асуулт

GitHub дээр файл зөв хадгалагдахгүй эсвэл олдохгүй байвал ямар шалтгаан байж болох вэ? Код бичихгүйгээр 3 боломжит шалтгаан болон шалгах аргыг тайлбарла.

## 3. AI-ийн санал болгосон 3 боломжит шалтгаан

### Шалтгаан 1: Файлын нэр эсвэл зам буруу

- **Таамаглал:** Файл өөр хавтас дотор эсвэл буруу нэртэй байж болно.
- **Шалгах арга:** Repository доторх хавтас болон файлын нэрийг шалгах.

### Шалтгаан 2: Өөрчлөлт commit хийгдээгүй

- **Таамаглал:** Файлыг зассан боловч өөрчлөлтийг хадгалаагүй байж болно.
- **Шалгах арга:** Commit хийсэн эсэх, өөрчлөлт repository дээр харагдаж байгаа эсэхийг шалгах.

### Шалтгаан 3: Буруу branch дээр ажилласан

- **Таамаглал:** Өөрчлөлтийг өөр branch дээр хийсэн байж болно.
- **Шалгах арга:** Одоо аль branch дээр байгааг болон файлыг тухайн branch дээр байгаа эсэхийг шалгах.

## 4. Миний хийсэн шалгалт

- Repository-ийн `docs` хавтсыг нээсэн.
- `ai-log.md` болон `debug-log.md` файлууд байгаа эсэхийг шалгасан.
- Хоёр файл хоёулаа `docs` хавтас дотор харагдаж байгааг ажигласан.

## 5. Шалгалтын үр дүн

- **Хүлээсэн үр дүн:** Хоёр файл `docs` хавтас дотор байх.
- **Ажигласан үр дүн:** Хоёр файл хоёулаа `docs` хавтас дотор харагдсан.
- **Дүгнэлт:** Файлын нэр, байрлал зөв байгааг шалгасан. Гэхдээ энэ шалгалт нь commit болон branch-ийн бүх боломжит асуудлыг туршсан гэсэн үг биш.

## 6. Миний дүгнэлт

AI-ийн санал болгосон шалтгаануудыг шууд үнэн гэж үзэж болохгүй. Тус бүрийг шалгаж, ажигласан үр дүнд үндэслэн дүгнэх хэрэгтэй. Энэ удаа би файлын нэр болон байрлалыг шалгасан. Дараагийн удаа commit болон branch-ийн төлөвийг тусад нь шалгана.
