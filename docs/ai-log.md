# L06 — AI ашигласан тэмдэглэл

## 1\. Асуудал

GitHub дээр файл зөв хавтас, branch дээр хадгалагдсан эсэхийг шалгахдаа ямар шалтгаануудыг эхэлж шалгах вэ?

## 2\. AI-д тавьсан асуулт

"GitHub дээр файл олдохгүй эсвэл өөрчлөлт харагдахгүй байвал код бичихгүйгээр 3 боломжит шалтгаан, тус бүрийг шалгах аргыг тайлбарла."

## 3\. AI-ийн 3 таамаглал

1. **Файлын зам/нэр буруу:** Repository-ийн хавтас, filename болон case-ийг шалгах.
2. **Өөрчлөлт commit хийгдээгүй:** Commit history болон branch дээрх өөрчлөлтийг шалгах.
3. **Өөр branch дээр ажилласан:** Одоогийн branch болон тухайн branch-ийн файлын жагсаалтыг харьцуулах.

Эдгээр нь эхний таамаглал бөгөөд батлагдсан шалтгаан гэж шууд үзэхгүй.

## 4\. Шалгалт ба нотолгоо

|Таамаглал|Шалгах арга|Одоогийн нотолгоо|Дүгнэлт|
|-|-|-|-|
|Файлын зам/нэр буруу|Repository-ийн docs хавтсыг нээж файлын нэрийг шалгах|Өмнө нь ai-log.md, debug-log.md хоёр docs дотор байгааг харсан|Энэ хоёр файлын зам зөв байсан|
|Commit хийгдээгүй|Commit history болон өөрчлөлтийн diff шалгах|Энэ тэмдэглэлд өмнөх бодит алдааны commit SHA хавсаргаагүй|Туршилт дутуу|
|Буруу branch|main болон ажлын branch-ийн файлыг харьцуулах|Өмнөх PR #8 нь 0 changed files-тэй байсан тухай шалгалтын бүртгэл бий|Branch/diff-ийг хамтад нь шалгах шаардлагатай|

## 5\. Буруу таамаглалыг няцаах туршилт

Багшийн шаардлагаар AI-ийн 3 таамаглалаас дор хаяж нэгийг бодит туршилтаар няцаах ёстой. Энэ repository-д файлын зам/нэр буруу гэсэн таамаглалыг бодит туршилтаар няцаасан. Харин commit хийгдээгүй болон буруу branch гэсэн таамаглалуудыг тус тусад нь бүрэн шалгаагүй тул одоогоор батлагдсан эсвэл няцаагдсан гэж дүгнэхгүй.

Туршилт хийх үед:

### Туршсан таамаглал

Файлын зам болон нэр буруу байгаа тул GitHub дээр файл олдохгүй байна.

### Яг хийсэн алхам

1. `Test-Path .\docs\ai-log.md` командаар локал файлыг шалгав.
2. `git ls-files --error-unmatch docs/ai-log.md` командаар Git-д бүртгэгдсэн эсэхийг шалгав.
3. `git ls-tree -r --name-only origin/main -- docs/ai-log.md` командаар GitHub-ийн main branch дээрх файлын замыг шалгав.
4. `git branch --show-current` командаар одоогийн branch-ийг шалгав.

### Хүлээсэн үр дүн

Файл буруу замтай бол локал шалгалт амжилтгүй болох эсвэл GitHub-ийн main branch дээр тухайн зам олдохгүй байх ёстой.

### Бодит үр дүн

- Локал шалгалт: `True`
- Git-д бүртгэгдсэн зам: `docs/ai-log.md`
- GitHub origin/main дээрх зам: `docs/ai-log.md`
- Одоогийн branch: `main`
- `git status --short`: өөрчлөлт байхгүй.

### Няцаасан эсэх

Энэ файлын хувьд буруу зам/нэр гэсэн таамаглалыг няцаав. Файл локал болон GitHub-ийн main branch дээр зөв замтай байна.

### Огноо / commit SHA

- Огноо: 2026-11-16
- Commit SHA: `d8df341f7c04a2fb8c68837ccb8ff36a45cca100`
## 6\. Миний дүгнэлт

AI-ийн санал бол баталгаатай үнэн биш, шалгаж үзэх таамаглал юм. Файлын зам/нэр буруу гэсэн таамаглалыг локал файл, Git index болон origin/main дээр шалгаж няцаасан. Харин commit хийгдээгүй болон буруу branch гэсэн таамаглалуудыг бүрэн шалгаагүй тул эдгээрийг шалгах ажил үлдсэн.



## 7. Нэмэлт бодит кодын туршилт

### Шалгасан нөхцөл

Барааны үлдэгдэл 5-аас бага үед бага үлдэгдэлтэй барааг шүүх нөхцөлийг шалгав.

### Туршилтын өгөгдөл

| SKU | Үлдэгдэл |
|---|---:|
| A01 | 4 |
| A02 | 5 |
| A03 | 6 |

### JavaScript туршилт

Ашигласан нөхцөл: `balance < 5`

Бодит үр дүн: зөвхөн A01 (4) гарсан.

**Төлөв: PASS**

### Python туршилт

Ашигласан нөхцөл: `product["balance"] < 5`

Бодит үр дүн: зөвхөн A01 (4) гарсан.

**Төлөв: PASS**

### Дүгнэлт

Хоёр хэл дээрх туршилт ижил үр дүн өгсөн.

Үлдэгдэл яг 5 байх үед бараа бага үлдэгдлийн жагсаалтад орохгүй.

Тайлбар: Энэ нь кодын нөхцөлийг шалгасан нэмэлт туршилт бөгөөд дээрх GitHub-тэй холбоотой 3 таамаглалыг няцаасан нотолгоо биш.
