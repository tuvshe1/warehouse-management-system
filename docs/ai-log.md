# L06 AI ашигласан тэмдэглэл

## 1. Асуулт
GitHub дээр ажиллах үед алдаа гарвал шалтгааныг яаж олох вэ?

## 2. AI-ийн зөвлөгөө
AI дараах 3 боломжит шалтгааныг шалгахыг зөвлөсөн.

1. Файлын нэр эсвэл зам буруу байх.
2. Өөрчлөлт хадгалагдаагүй байх.
3. Branch эсвэл commit буруу байх.

## 3. Шалгах арга
- Файлын нэр болон байрлалыг шалгах.
- Өөрчлөлт хадгалагдсан эсэхийг шалгах.
- Одоо ашиглаж байгаа branch-аа шалгах.

## 4. Миний дүгнэлт
AI-ийн зөвлөгөөг шууд зөв гэж үзэхгүй. Боломжит шалтгаануудыг тус тусад нь шалгаж, үр дүнд үндэслэн дүгнэнэ.
