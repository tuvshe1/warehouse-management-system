# L05 Эрсдэлийн төлөвлөгөө

## 1. Цаг хүрэлцэхгүй байх
- **Эрсдэл:** Төлөвлөсөн ажлаа хугацаанд нь дуусгахгүй байх.
- **Хариуцах хүн:** Би
- **Шийдэл:** Эхлээд үндсэн ажлуудаа хийж, нэмэлт ажлыг дараа нь хийнэ.

## 2. Интернэт тасрах
- **Эрсдэл:** GitHub ашиглаж чадахгүй болох.
- **Хариуцах хүн:** Би
- **Шийдэл:** Интернэт сэргэх хүртэл хийх ажлаа тэмдэглэж, дараа нь GitHub-д оруулна.

## 3. Git алдаа гарах
- **Эрсдэл:** Branch, commit эсвэл merge хийхэд алдаа гарах.
- **Хариуцах хүн:** Би
- **Шийдэл:** Алдааны мэдээллийг уншиж, нэг өөрчлөлт хийгээд дахин шалгана.

## 4. Ойлгоогүй зүйл гарах
- **Эрсдэл:** Код болон шаардлагыг ойлгохгүй байх.
- **Хариуцах хүн:** Би
- **Шийдэл:** Баримт бичиг уншиж, багшаас асууж, AI-ийн зөвлөгөөг туршиж шалгана.

## 5. Ажлын хэмжээ нэмэгдэх
- **Эрсдэл:** Төлөвлөөгүй нэмэлт ажил үндсэн ажлыг удаашруулах.
- **Хариуцах хүн:** Би
- **Шийдэл:** Үндсэн ажлаа дуусгасны дараа нэмэлт боломжуудыг хийнэ.

## Миний дүгнэлт
Төслийн явцад янз бүрийн эрсдэл гарч болно. Тиймээс эрсдэл бүрд урьдчилан шийдэл төлөвлөсөн. Ингэснээр ажлаа илүү зөв зохион байгуулна.
